# LEX Exam Prep ⚡

This is the React-only version of LEX, built with Vite.

- `index.html` is Vite's small root page that mounts React.
- `src/main.jsx` starts the React application.
- `src/App.jsx` contains the app screens and interactions.
- `src/index.css` contains the styling.

## Run it

Open this folder in VS Code and run these commands in its terminal:

```bash
npm install
npm run dev
```

Open the local address printed by Vite. Keep the terminal open while using the site.

Login and signup are demo-only and store data in the browser. Real candidate accounts require a secure backend.
